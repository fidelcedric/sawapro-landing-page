# SawaPro Auto Repair Landing Page

A premium, fully responsive landing page for **SawaPro Auto Repair Limited** — Nairobi's premier luxury SUV specialist. Built with vanilla HTML, Tailwind CSS, and native JavaScript.

## Features

- **Hero Section** — Bold full-screen hero with headline, CTA buttons, and live statistics counters (500+ SUVs serviced, 10+ years, 98% satisfaction)
- **Services Grid** — 6 service cards with custom SVG icons, staggered scroll animations, and hover effects
- **Why Choose Us** — Dark-themed value proposition section with glassmorphism cards and floating background orbs
- **Image Gallery** — Before/after transformation showcase with hover overlay captions
- **Contact Section** — Phone, address, hours, Google Maps embed, and prominent call-to-action button
- **Mobile Navigation** — Hamburger menu with smooth open/close transitions
- **Scroll Animations** — Intersection Observer-based fade-up animations with staggered delays
- **Responsive Design** — Fully adaptive from mobile to ultrawide desktop

## Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Semantic page structure |
| Tailwind CSS (CDN) | Utility-first styling, responsive layout |
| CSS3 | Custom animations, keyframes, gradient overlays |
| Vanilla JavaScript | Intersection Observer, mobile menu, smooth scroll |
| Google Maps Embed | Location iframe |
| Inter Font | Clean, modern typography |

## Getting Started

```bash
git clone https://github.com/fidelcedric/sawapro-landing-page.git
cd sawapro-landing-page
# Open index.html in your browser — no build step needed
open index.html
```

Since the project uses Tailwind CSS via CDN and zero build tooling, it runs instantly in any browser. No npm install, no bundler configuration.
