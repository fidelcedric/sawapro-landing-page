# SawaPro Landing Page

A static landing page concept for an auto repair business. It uses HTML, Tailwind CSS from a CDN, and vanilla JavaScript. It runs on GitHub Pages.

The business name, phone number, address, map, gallery images, and statistics are sample content used to show the layout. Replace them with verified details before using this page for a real shop.

## What is in the page

- Full-screen hero with calls to action and sample statistics
- Six service cards with SVG icons and scroll animations
- Before-and-after gallery, value proposition section, and contact section
- Mobile navigation and Intersection Observer fade-in effects

## Run it locally

```bash
git clone https://github.com/fidelcedric/sawapro-landing-page.git
cd sawapro-landing-page
# Open index.html in a browser. No build step or package install is needed.
```

The page loads Tailwind CSS and fonts from CDNs, so it needs an internet connection.
